# FocusBloom Assets

This directory contains the app's visual assets.

## Required Assets

- `splash.png` — Splash screen (1242x2436px recommended)
- `adaptive-icon.png` — Android adaptive icon foreground (1080x1080px)
- `favicon.png` — Web favicon (48x48px)
- `notification-icon.png` — Notification icon (48x48px, white on transparent)

## Icon Design

The app icon uses a **seedling sprouting from a book** motif, representing growth and study. The color palette matches the app's theme:

- Primary: Forest green (#2D5A3D)
- Secondary: Warm amber (#D4A373)
- Background: Cream (#F8F4E9)

## Creating Assets

Use a tool like [Figma](https://figma.com) or [GIMP](https://gimp.org) to create the assets.
Export at the recommended sizes above.

For Android adaptive icons, use the [Android Asset Studio](https://romannurik.github.io/AndroidAssetStudio/).
